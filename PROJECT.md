# Strand City Viewer

Explore the streets within 2 km of King's College London's Strand campus on foot, by vehicle, or from the air.

Run `npm start` or `npm run dev` from the repository root and open [localhost:8080](http://localhost:8080/). In IntelliJ IDEA, use the **Strand City Viewer** run configuration.

The [City Viewer guide](city-viewer/README.md) covers controls, map data, and the modding API.
